Condizioni di Esistenza (C.E.)

Determina il dominio/condizioni di esistenza delle seguenti frazioni algebriche.

Ex 1.
\(\frac{3x + 1}{x^2 - 4}\)
Risultato: \(x \neq \pm 2\)
Mostra Svolgimento Passo-Passo

Svolgimento guidato:

  1. Affinché la frazione sia definita, il denominatore deve essere diverso da zero: \(x^2 - 4 \neq 0\).
  2. Scomponiamo il denominatore (differenza di quadrati): \((x - 2)(x + 2) \neq 0\).
  3. Legge di annullamento del prodotto: \(x - 2 \neq 0 \implies x \neq 2\) e \(x + 2 \neq 0 \implies x \neq -2\).
  4. Condizione Finale: \(C.E.: x \neq \pm 2\).

Semplificazione di Frazioni Algebriche

Scomponi in fattori numeratore e denominatore e riduci ai minimi termini.

Ex 16.
\(\frac{x^2 - 9}{x^2 + 6x + 9}\)
Risultato: \(\frac{x - 3}{x + 3}\)   (con \(x \neq -3\))
Mostra Svolgimento Passo-Passo

Svolgimento guidato:

  1. Scomponiamo il numeratore: \(x^2 - 9 = (x - 3)(x + 3)\).
  2. Scomponiamo il denominatore: \(x^2 + 6x + 9 = (x + 3)^2\).
  3. Condizioni di Esistenza: \((x+3)^2 \neq 0 \implies x \neq -3\).
  4. Semplifichiamo il fattore comune \((x + 3)\): $$\frac{(x - 3)(x + 3)}{(x + 3)^2} = \frac{x - 3}{x + 3}$$

Addizione e Sottrazione

Calcola il minimo comune denominatore (m.c.d.) ed effettua le somme algebriche.

Ex 31.
\(\frac{1}{x - 1} + \frac{2}{x + 1} - \frac{2x}{x^2 - 1}\)
Risultato: \(\frac{1}{x + 1}\)   (\(x \neq \pm 1\))
Mostra Svolgimento Passo-Passo

Svolgimento guidato:

  1. Scomponiamo i denominatori: \(x^2 - 1 = (x - 1)(x + 1)\).
  2. C.E.: \(x \neq 1 \land x \neq -1\).
  3. mcm = \((x - 1)(x + 1)\). Riduciamo ad unico denominatore: $$\frac{1(x + 1) + 2(x - 1) - 2x}{(x - 1)(x + 1)}$$
  4. Sommiamo al numeratore: \(\frac{x + 1 + 2x - 2 - 2x}{(x - 1)(x + 1)} = \frac{x - 1}{(x - 1)(x + 1)}\).
  5. Semplifichiamo \((x - 1)\): \(\frac{1}{x + 1}\).

Equazioni Fratte

Poni le C.E., risolvi l'equazione fratta e verifica l'accettabilità delle soluzioni.

Ex 61.
\(\frac{2}{x - 1} + \frac{1}{x + 1} = \frac{4}{x^2 - 1}\)
Risultato: \(x = 1 \implies \text{Impossibile}\)
Mostra Svolgimento Passo-Passo

Svolgimento guidato:

  1. Scomponiamo: \(x^2 - 1 = (x - 1)(x + 1)\).
  2. C.E.: \(x \neq 1 \land x \neq -1\).
  3. Moltiplichiamo per il mcm \((x - 1)(x + 1)\): $$2(x + 1) + 1(x - 1) = 4$$
  4. Risolviamo: \(2x + 2 + x - 1 = 4 \implies 3x + 1 = 4 \implies 3x = 3 \implies x = 1\).
  5. Verifica C.E.: Poiché le C.E. richiedono \(x \neq 1\), la soluzione \(x = 1\) non è accettabile.
  6. Esito: Equazione Impossibile (\(S = \emptyset\)).

Problemi Geometrici, Fisici ed Economici

Modella il problema reale con le frazioni algebriche e calcola l'espressione o il valore richiesto.

Ex 76.
Geometria - Rettangolo Un rettangolo ha area \(A = \frac{x^2 - 16}{x + 2}\) e base \(b = \frac{x - 4}{x^2 - 4}\). Determina l'espressione dell'altezza \(h = \frac{A}{b}\) in forma semplificata.
Risultato: \(h = (x + 4)(x - 2)\)   (\(x > 4\))
Mostra Svolgimento Passo-Passo

Svolgimento guidato:

  1. L'altezza \(h\) è data da \(A : b\): $$h = \frac{x^2 - 16}{x + 2} : \frac{x - 4}{x^2 - 4} = \frac{x^2 - 16}{x + 2} \cdot \frac{x^2 - 4}{x - 4}$$
  2. Scomponiamo: $$h = \frac{(x - 4)(x + 4)}{x + 2} \cdot \frac{(x - 2)(x + 2)}{x - 4}$$
  3. Semplifichiamo a croce \((x - 4)\) e \((x + 2)\): $$h = (x + 4)(x - 2)$$
  4. Discussione geometrica: per avere lunghezze positive occorre \(x > 4\).
Ex 77.
Fisica / Portate di Flusso Due rubinetti versano acqua in una vasca. Il primo ha portata \(V_A = \frac{1}{x + 1}\) L/s, il secondo ha portata \(V_B = \frac{1}{x - 1}\) L/s. Esprimi la portata totale \(V_{\text{tot}} = V_A + V_B\).
Risultato: \(V_{\text{tot}} = \frac{2x}{x^2 - 1}\)   (\(x > 1\))
Ex 78.
Geometria - Trapezio In un trapezio, la base maggiore è \(B = \frac{3x + 6}{x - 1}\), la base minore è \(b = \frac{x + 2}{x - 1}\) e l'altezza è \(h = \frac{x - 1}{x + 2}\). Calcola l'Area del trapezio.
Risultato: \(\text{Area} = 2\)   (\(x > 1\))
Ex 79.
Economia - Costo Medio Un'azienda ha costi fissi per \(500\text{ €}\) e costi variabili di \(15\text{ €}\) per pezzo. Il costo medio per pezzo è \(C(x) = \frac{15x + 500}{x}\). Quanti pezzi \(x\) produrre affinché il costo medio scenda a \(25\text{ €}\)?
Risultato: \(x = 50 \text{ pezzi}\)
Ex 80.
Fisica - Resistenza Equivalente In un circuito elettrico, due resistenze in parallelo valgono \(R_1 = \frac{x + 2}{x}\) \(\Omega\) e \(R_2 = \frac{x + 2}{2}\) \(\Omega\). Calcola la resistenza equivalente \(R_{\text{eq}} = \frac{R_1 R_2}{R_1 + R_2}\).
Risultato: \(R_{\text{eq}} = \frac{x + 2}{x + 2} = 1 \text{ (se } x = 2 \text{)}\)  \(\implies \frac{x + 2}{x + 2}\)
Ex 81.
Cinematica - Velocità Media Un veicolo percorre un tragitto di lunghezza \(d\) all'andata a velocità \(v_1 = x+1\) e al ritorno a velocità \(v_2 = x-1\). Esprimi il tempo totale di percorrenza \(t_{\text{tot}} = \frac{d}{v_1} + \frac{d}{v_2}\) in forma raccolta.
Risultato: \(t_{\text{tot}} = \frac{2dx}{x^2 - 1}\)   (\(x > 1\))
Ex 82.
Geometria - Triangolo Rettangolo I cateti di un triangolo rettangolo misurano \(a = \frac{2x}{x^2 - 1}\) e \(b = \frac{x^2 - 1}{x^2 + 1}\). Esprimi il doppio dell'Area \(2A = a \cdot b\) in forma semplificata.
Risultato: \(2A = \frac{2x}{x^2 + 1}\)   (\(x > 1\))
